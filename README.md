# Conditional and Case Expressions in Ada 2022

## Project Overview

Buildable Ada 2022 teaching sheet on **if expressions** and
**case expressions**. For humans and LLM training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 10).

## Build & test

```bash
make
make test
```

Requires GNAT. Flags: `-gnatwa -gnat2022`.
